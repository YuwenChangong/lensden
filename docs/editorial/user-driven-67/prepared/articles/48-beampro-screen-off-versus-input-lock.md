# Beam Pro's Screen Is Dark: Is Playback Continuing, and Are Inputs Locked?

A historical [Beam Pro first-week account](https://www.reddit.com/r/Xreal/comments/1e8rfa9/first_24_hours_on_beam_pro/) describes discovering an Anti Mistouch control and changing several settings while trying to extend viewing time. The owner's later runtime estimate reflects that whole set of changes. It is not a measured guarantee for current software or proof of one setting's individual power saving.

The practical distinction is between dimming or switching off the source screen, preventing unwanted touch input and stopping the session. These states may look similar from outside but affect use differently. A device that appears dark is not necessarily inactive.

## Check the intended current behaviour

Use the current vendor instructions for the exact Beam Pro software. XREAL's [nebulaOS 2.0 announcement](https://www.reddit.com/r/Xreal/comments/1qwjp19/major_update_nebulaos_20_is_live_beam_pro_my/) documents a redesigned interface, so a historical control label or shortcut should not be assumed to remain unchanged.

For ordinary seated playback, identify how to prevent unintended touches and how to deliberately pause or end the session. Confirm that you can restore controls without pulling on the glasses cable. Do not rely on repeatedly tapping a blank screen when the input state is unclear.

## Keep storage and active use separate

Do not operate a powered device inside a closed bag merely to see whether it stays awake. For transport, follow the manufacturer's storage and power instructions and keep hot equipment ventilated. An input-lock feature is not evidence that enclosed active operation is intended.

If accidental inputs occur during normal handling, record the active mode, whether the lock indicator was visible and which action changed playback. Do not infer a firmware defect simply because another owner uses the word lock differently.

## Avoid inventing a battery claim

The source writer changed screen, battery-saving and wireless settings together. Repeating their final hours as a guaranteed benefit of Anti Mistouch would overstate the evidence. Record your own ordinary session separately and distinguish an on-screen estimate from elapsed runtime.

For a buying decision, ask whether the device can perform the intended playback and control arrangement without frequent intervention. A dark source screen alone is not the goal.
