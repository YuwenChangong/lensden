# An AI Answer Is Slow: Separate Connection Recovery From Answer Generation

A [RayNeo iO owner review on LINUX DO](https://linux.do/t/topic/2859513?tl=en) originally described connection trouble with a particular HarmonyOS beta arrangement, then edited the account after a native beta app improved the experience. Keeping that update visible matters. It prevents an obsolete workaround from being reported as the current state of every iO installation.

For latency, “the AI is slow” can hide several waits: waking the device, reconnecting the app, recognising speech, sending a request and presenting an answer. An improvement at one stage does not establish that the underlying answer service became faster.

## Time the event you actually care about

For an ordinary non-sensitive question, note when the device acknowledges activation, when it recognises the request and when a useful result appears. Do not manufacture an average from a few convenient attempts. If timing was only estimated, say so; a screen recording with no common start point can also mislead.

Keep language, network and app state recorded. A first request after the app has been in the background is different from a second request in an active session. If that difference matters to your daily routine, preserve it rather than blending both into one speed rating.

## Do not mix RayNeo product families

iO, V3 and display-focused Air products address different functions. A caption appearing in a display and a spoken answer on another pair are different output paths. Do not transfer a latency result or a firmware version between them merely because the companion apps share branding.

Use the [manufacturer's support portal](https://www.rayneo.cn/help.html) to identify the relevant product instructions, and the exact app publisher's release history for software context. A support page for an older Air connection cannot establish iO's AI processing stages. Where the vendor does not document a stage, leave it Unknown.

## Judge usefulness, not just speed

A quick but incorrect answer may be less useful than a slower request that asks for clarification. Choose a question whose answer can be checked independently and record both timing and correctness. Do not use a casual glasses assistant for decisions requiring authoritative professional information.

If the delay begins with reconnection, send that sequence to support instead of assuming a particular AI model is responsible.
