# A Clear Centre and Soft Corners: Make an Edge-Visibility Map

A complaint about blurry corners becomes more useful when it identifies which corners and under what position. In a [developer discussion about a virtual HDMI monitor](https://news.ycombinator.com/item?id=44245709), an XREAL Air 2 user described difficulty bringing the whole image into focus even with the glasses close to the forehead. The example concerns that wearer's setup; it does not establish how every Air 2 fits or how One Pro behaves.

The distinction is between seeing a complete rectangle and reading detail inside it. A missing bottom edge is clipping. Visible letters that lose definition toward an edge are a different observation. Both can occur together, but treating them as one problem makes accessory advice imprecise.

## Build a position map

Use an ordinary document with labels at the centre and four corners. Start with the supplied fit arrangement, then try only adjustments documented for the exact frame. For each arrangement, write down whether every label is visible, readable and comfortable without holding the frame in place. Keep the source, font size and output mode fixed during this pass.

Check each eye separately for a brief comparison, without pressing on the eye or forcing the glasses. If moving the frame improves one edge but spoils another, record that trade-off. A photograph through a lens can document an observation, but camera alignment can introduce its own clipping; it is not a substitute for describing what the wearer sees.

## Separate an acceptable workaround from a mismatch

Placing menus nearer the centre may make a particular application usable. It does not mean the edge has become sharper. Likewise, shrinking an application window is a workflow choice, not proof that a frame now offers uniform clarity. Decide whether the workaround still lets you see subtitles, status bars or the controls you actually need.

Consult the [One-series manufacturer guide](https://us.shop.xreal.com/blogs/buying-guide/user-guide_xreal-one-series) only for the models it names; older Air-series users need their own supplied manual. Do not transplant an adjustment range merely because both products carry the XREAL brand.

If a practical supported fit never reveals the whole task, preserve the map and ask about the return process while it remains available. Do not grind pads or bend hinges to chase a forum photograph.
