# The Screen Moves When the Plane Turns: Record the Tracking Mode Before Calling It Drift

An [XREAL One passenger report](https://www.reddit.com/r/Xreal/comments/1icxva5/) describes an anchored screen shifting when the plane turns. The replies debate sensors and reference frames. Those explanations should not be treated as a verified description of the device's internal tracking algorithm.

For the wearer, the immediate distinction is simpler: a directional anchor is not automatically a promise that a screen will remain attached to the seat in a moving cabin. A result observed during transport also cannot establish how the same mode behaves at a stationary desk.

## Name the mode and the equipment

Record the exact glasses, any intermediary or camera accessory, selected mode and software versions. “Pinned” is not a sufficient technical description. Built-in orientation anchoring and a system using positional tracking can have different requirements and failure modes.

The [manufacturer's One-series guide](https://us.shop.xreal.com/blogs/buying-guide/user-guide_xreal-one-series) distinguishes Anchor and Follow. [XREAL's Spatial Anchor documentation](https://tutorials.xreal.com/docs/accessories/eye/how-to-use/6dof/) concerns an additional supported tracking arrangement. Do not assume a camera-free setup has the same capabilities because both interfaces use the word anchor.

## Make the report useful without extending the session

If a normal seated viewing session reveals movement, note whether the cabin was turning and whether the screen moved relative to the window, the seat or the wearer's head. Do not perform a disruptive experiment in a vehicle or use immersive viewing while driving. Follow venue and transport rules, and stop if the experience is uncomfortable.

For a later stationary comparison, use the same supported mode and ordinary source. Record whether the symptom is absent there. That can identify the environmental condition associated with the report without proving the algorithm behind it.

## Avoid the unsupported fix

Do not calibrate against improvised moving references or install unofficial tracking modifications merely because a comment names an IMU or compass. Ask the manufacturer which mode is intended for the actual environment. A supported Follow option may be worth checking, but it is not a guarantee of comfortable travel viewing.
