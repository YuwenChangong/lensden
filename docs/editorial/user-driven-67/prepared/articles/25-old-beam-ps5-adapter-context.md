# An Old PS5 Cable Complaint Still Explains Why Connection Direction Matters

In a historical [PS5 and XREAL Beam support thread](https://www.reddit.com/r/Xreal/comments/1829kee/), an Air owner can see the Beam interface but not the console. After a reply asks about the powered adapter, the owner realises the cable choice needs reconsideration. That exchange explains a purchasing mistake; it does not prove the newly ordered replacement eventually worked.

Keep the hardware context intact: original Beam and Air are not Beam Pro and One Pro. A support reply in the same historical thread also describes a refresh limitation for that Beam path. It should not be copied into a current One-series specification or applied to an unrelated HDMI converter.

## Draw the arrows before ordering

Write the source first: PS5 HDMI output. Then identify the converter's documented HDMI input and glasses-compatible output, plus any required power connection. A cable advertised for a laptop's USB-C output to a television's HDMI input describes the opposite job. Connector shapes and the word “bidirectional” in an unrelated listing are insufficient evidence.

[VESA's DisplayPort FAQ](https://www.displayport.org/faq/) describes the separate capability of carrying DisplayPort over USB-C. A USB-C receptacle alone is not a complete statement about video direction, conversion or power. Verify those against the accessory maker's instructions for the actual part number.

## An interface picture is not the incoming console

An intermediary showing its own menu establishes that the glasses can display that menu. It does not prove the intermediary is receiving the PS5 signal. Record whether the console recognises an external display and what the adapter documentation requires before changing optional resolution settings.

Start from a documented basic mode. A premium HDMI cable cannot make an intermediary support a mode it does not accept. Avoid buying several cables solely because the glasses' panel is advertised with a higher refresh figure.

## Keep old advice in its own generation

If using One-series glasses directly through a different converter, consult the [current manufacturer connection guide](https://us.shop.xreal.com/blogs/buying-guide/user-guide_xreal-one-series) instead of assuming the older Beam chain is mandatory. Ask whether the accessory supports the desired complete configuration, including audio and any protected playback.

[Lensden's PS5 guide](/guides/ps5-ar-glasses-hdmi-adapter-power-audio/) covers the general connection choices; this report adds the distinction between an intermediary's menu and an incoming source.
