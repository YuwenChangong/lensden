# A 120 Hz Adapter List Is a Test Record, Not a Permanent Compatibility Guarantee

A historical [community adapter comparison](https://www.reddit.com/r/Xreal/comments/166cm60/) records different 120 Hz results across several powered HDMI-to-USB-C products. Its author identifies a Windows mini-PC as the test source and includes observations from another tester. That context makes the list useful, but also limits what a buyer can infer from it years later.

A current marketplace listing may reuse a product name while its hardware, cable or firmware has changed. Equally, a result with XREAL Air and a particular source does not certify One Pro, a console or an entirely different glasses family. Preserve the original test conditions when citing the list.

## Ask what “120 Hz” describes

Distinguish the display's supported mode, the mode the source negotiated and the game's rendered frame rate. A game showing a performance counter above 60 does not by itself establish a 120 Hz output. A source reporting 120 Hz also does not prove the game supplies 120 different frames each second.

Use the source's output-information screen and the accessory maker's supported-mode table. Record resolution alongside refresh and any restrictions associated with audio, 3D or protected playback. Avoid treating a large bandwidth number on the adapter box as a substitute for those mode combinations.

## Keep the first test simple

Establish a stable documented basic mode before attempting the desired higher mode. Change only the output setting during the comparison. If video or audio fails, keep that result attached to the exact chain rather than declaring the entire product family unsupported.

[XREAL's current specifications](https://tutorials.xreal.com/docs/glasses/one-series/spec/) describe the named glasses models, while the adapter manufacturer must establish the converter's side. Those are complementary sources of information. Neither a glasses specification nor a community vote can supply a missing converter capability.

## Make the record useful to the next buyer

When sharing an observed result, name the adapter revision, source, operating system, glasses, power arrangement and firmware where known. State how output refresh was checked. A clear Unknown for an untested mode is more useful than extending one successful combination into an “all devices” claim.
