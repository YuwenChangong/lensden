# Stable on a PC, Unstable on Beam Pro: What That Comparison Actually Shows

A detailed [XREAL 1S report](https://www.reddit.com/r/Xreal/comments/1v57tmf/screen_flickering_and_tearing_after_my_glasses/) identifies flickering through Beam Pro while the same glasses appear stable on a direct computer connection. The writer supplies My Glasses 2.2.0 (28.19), glasses firmware 15.1.03.442_20260722 and nebulaOS x4000_x502_260518_ROW. These are the reported versions, not Lensden measurements or proof of a confirmed regression.

This is a better starting point than a complaint that every video stutters. It supplies a comparison path and enough software identity for support to ask a narrower question. It does not conclusively clear the cable, glasses or intermediary: different paths can exercise the same components differently.

## Keep the content identical

Use the same ordinary local clip or harmless text page where supported. A local file on the PC compared with an internet stream on Beam Pro changes both source and delivery. If the comparison necessarily changes the application, write that limitation down instead of describing it as a controlled reproduction.

Record whether the issue affects the rendered video, the surrounding app window or the device interface. Those observations can point support toward different parts of the chain without naming an unproven cause. An animation that shakes while a menu remains stable is not the same result as the whole connection disappearing.

## Do not hide later replies

The discussion contains differing follow-ups, including another owner who reports improvement after a further update and others who still describe problems. That prevents a blanket statement that a single release fixed everyone. Preserve the original report's versions and distinguish each participant's hardware.

XREAL's [nebulaOS 2.0 announcement](https://www.reddit.com/r/Xreal/comments/1qwjp19/major_update_nebulaos_20_is_live_beam_pro_my/) documents a changing software platform. A platform announcement is not confirmation of the cause or resolution of every later user issue.

For your own support request, a compact comparison is enough: source A and mode, source B and mode, exact versions, observed difference and an ordinary sample that demonstrates it. Do not install unofficial firmware or remove security controls simply to match somebody else's experiment.

If the direct path meets the immediate task, it can remain a practical fallback while support investigates. It does not reproduce the spatial workspace supplied by the intermediary. [Lensden's tracking guide](/guides/3dof-6dof-tracking/) explains that separate capability question. Sources reviewed November 3, 2026; this article does not claim the reported behaviour persists on today's releases.
