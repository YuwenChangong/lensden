## 这是什么

Lensden 是独立的 AR/AI 眼镜数据库、产品比较资源与社区。我们按来源整理各品牌产品的规格参数、兼容条件和开发者资源，为选购和技术决策提供参考。

可从[设备库与比较工具](/products/)、[指南](/guides/)和[社区](/feed/)开始。收录产品不代表厂商认可或合作；基于公开资料的内容不代表 Lensden 已进行实验室测试或亲身使用。

网站由 Jayden 发起和维护。

## 为什么做

AR/AI 眼镜品类正在快速扩展，但中文互联网上缺少一份系统化、中立、持续更新的参考资料。各厂商官网信息分散，科技媒体报道偏重时效性，社区讨论碎片化。

我们想做的是一个稳定的、结构化的信息来源。

## 内容立场

- 不售卖任何产品，不接入电商链接
- 不接受品牌付费推广或赞助内容
- 产品信息基于公开资料整理，标注「待核实」的数据正在逐步验证
- 不对任何品牌做主观推荐或排名
- Gaze Launcher 相关内容单独标注，与第三方产品内容区分

## 内容来源

- 厂商官网公开规格
- 开发者文档和 SDK 说明
- 已发布产品的公开评测
- 可复现的开发记录，注明适用平台、版本与限制

如发现内容错误，欢迎通过 [GitHub Issues](https://github.com/YuwenChangong/lensden/issues) 提交修正。

## 技术架构

本站基于以下技术栈构建：

- **Astro** + **Starlight** — 静态文档站点框架
- **Markdown/MDX** — 内容格式
- **Supabase** — 产品、新闻、论坛内容与身份数据
- **Cloudflare Workers** — 应用部署和静态资源服务
- **Pagefind** — 客户端全文搜索
- **GitHub** — 内容版本管理

文档与应用源码由 Git 仓库管理；设备、新闻和社区内容使用现有数据与审核流程。两者的变更和发布分别记录。
